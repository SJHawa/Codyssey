# 문제3 계산기 제작 계획

## 목표
- `PyQt`를 사용해 아이폰 계산기와 유사한 형태의 계산기 UI를 구현한다.
- 숫자 및 주요 버튼을 클릭했을 때 입력이 화면에 반영되도록 이벤트를 연결한다.
- 실제 계산 기능은 필수가 아니므로, 이번 단계에서는 UI와 입력 흐름을 안정적으로 완성하는 데 집중한다.
- 최종 결과물은 `calculator.py`로 저장한다.

## 작업 분해

### 1. 요구사항 정리
- 문제 문서의 필수 요구사항과 제약사항을 구현 관점으로 다시 정리한다.
- 필수 구현 범위와 보너스 범위를 구분한다.
- 사용할 라이브러리를 `PyQt`로 한정하고, 외부 패키지 사용 금지 조건을 확인한다.

### 2. 실행 환경 준비
- Python 3 실행 환경을 확인한다.
- `PyQt` 설치 여부를 확인하고, 미설치 시 설치한다.
- 실행 명령과 필요한 버전을 간단히 정리해 둔다.

### 3. UI 구조 설계
- 메인 창, 출력 영역, 버튼 영역으로 화면 구성을 나눈다.
- 아이폰 계산기와 유사한 버튼 배치를 정의한다.
- 필요한 버튼 목록을 정리한다.
  - 숫자: `0`~`9`
  - 기능: `.`, `=`, `+`, `-`, `*`, `/`
  - 보조: `AC`, `+/-`, `%`
- `0` 버튼의 가로 확장 등 대표적인 배치 특징을 반영할지 결정한다.

### 4. 화면 레이아웃 구현
- `calculator.py`에 기본 애플리케이션 실행 코드를 작성한다.
- 메인 윈도우와 디스플레이 라벨 또는 입력창을 만든다.
- 그리드 레이아웃으로 버튼을 배치한다.
- 색상과 크기는 완전 복제보다 “유사한 사용감”을 목표로 설정한다.

### 5. 버튼 생성 방식 정리
- 버튼을 하나씩 하드코딩할지, 버튼 정의 데이터를 기반으로 반복 생성할지 결정한다.
- 유지보수성과 코드 간결성을 위해 버튼 정보 리스트 또는 배열 기반 생성 방식을 우선 검토한다.
- 각 버튼의 텍스트, 위치, 크기, 스타일을 한곳에서 관리할 수 있게 구성한다.

### 6. 입력 이벤트 처리 구현
- 숫자 버튼 클릭 시 디스플레이에 값이 누적되도록 구현한다.
- 연산자 버튼 클릭 시 현재 입력 문자열에 기호가 추가되도록 구현한다.
- `AC` 버튼 클릭 시 입력을 초기화한다.
- `+/-`, `%`, `=` 버튼은 계산 기능이 필수가 아니므로 우선순위를 낮춘다.
  - 최소 구현안: 버튼 클릭이 동작은 하되, 화면 표시만 바꾸거나 임시 동작을 부여한다.

### 7. 예외 상황 및 입력 흐름 정리
- 초기 화면에 표시할 기본값을 정한다. 예: `0`
- 맨 앞의 불필요한 `0` 중복 입력을 어떻게 처리할지 정한다.
- 연산자 연속 입력 시 처리 방식을 정한다.
  - 예: 마지막 연산자로 교체
- 아직 계산 기능이 없더라도 사용자가 눌렀을 때 UI가 어색하지 않도록 최소한의 입력 규칙을 적용한다.

### 8. 스타일 및 가독성 정리
- PEP 8 스타일을 준수한다.
- 문자열은 기본적으로 작은따옴표를 사용한다.
- 대입문, 들여쓰기, 함수명 등 기본 스타일을 점검한다.
- 반복되는 UI 코드가 있다면 간단한 메서드로 분리한다.

### 9. 실행 및 동작 확인
- 프로그램이 경고 없이 실행되는지 확인한다.
- 주요 버튼이 정상적으로 눌리는지 확인한다.
- 숫자 입력과 초기화 동작을 직접 테스트한다.
- 레이아웃이 의도한 배치와 크게 다르지 않은지 확인한다.

### 10. 보너스 과제 확장 검토
- 기본 과제 완료 후 사칙연산 계산 기능을 추가할 수 있도록 확장 방향을 정리한다.
- 현재 입력값, 이전 입력값, 선택된 연산자를 상태로 관리하는 구조를 검토한다.
- 보너스 기능은 필수 구현과 분리해서 진행한다.

## 우선순위
1. 실행 환경 준비
2. UI 구조 및 버튼 배치 설계
3. `calculator.py` 기본 창과 디스플레이 구현
4. 버튼 생성 및 레이아웃 완성
5. 숫자/기본 버튼 입력 이벤트 연결
6. 초기화 및 입력 규칙 보완
7. 실행 테스트 및 스타일 정리
8. 보너스 기능 검토

## 산출물
- `calculator.py`
- 실행 가능한 계산기 UI
- 버튼 입력이 화면에 반영되는 기본 동작

## 검증 기준
- `calculator.py`가 Python 3 환경에서 실행된다.
- `PyQt` 기반 창이 정상적으로 표시된다.
- 숫자 버튼 클릭 시 디스플레이 값이 변경된다.
- `AC` 버튼 클릭 시 입력값이 초기화된다.
- 코드가 문제의 제약사항과 PEP 8 가이드를 크게 벗어나지 않는다.
