# Week09 Caesar Cipher Password Decoder Plan

## Summary
`week09` 폴더에 `plan.md`와 이후 구현 대상인 Python 스크립트 1개를 두는 전제로 진행한다. 스크립트는 `password.txt`를 안전하게 읽고, `caesar_cipher_decode(target_text)` 함수로 알파벳 26개 모든 자리수를 순회하며 해독 결과를 매 반복마다 출력한다. 사람이 눈으로 판별 가능한 해독 결과가 나오면 해당 자리수를 기준으로 최종 평문을 `result.txt`에 저장한다. 보너스 과제로는 간단한 텍스트 사전을 두고, 해독 결과에 사전 단어가 포함되면 반복을 조기 종료할 수 있게 설계한다.

## Key Changes
- 입력 파일 경로를 `week09/password.txt`로 고정하고, 읽기 실패 시 예외 메시지를 출력하고 종료한다.
- `caesar_cipher_decode(target_text)`는 다음 규칙으로 구현한다.
  - 인자명은 반드시 `target_text`를 사용한다.
  - 영문 대소문자는 자리수만큼 뒤로 되돌려 해독하고, 알파벳이 아닌 문자는 그대로 유지한다.
  - 자리수는 `0`부터 `25`까지 반복한다.
  - 각 반복마다 `n번째 자리수 해독 결과: ...` 형식으로 즉시 출력해 눈으로 확인 가능하게 한다.
- 최상위 실행 흐름은 다음 순서로 구성한다.
  - `password.txt` 읽기
  - 전체 자리수 해독 결과 출력
  - 사람이 식별한 올바른 자리수를 입력받기
  - 해당 결과를 `result.txt`에 저장
- 보너스 과제는 `dictionary_words` 같은 기본 리스트를 두고, 해독 결과에 특정 단어가 포함되면 다음 동작을 하도록 설계한다.
  - 자동 후보 판정 메시지 출력
  - 즉시 반복 중단
  - 중단된 자리수와 해독 문자열을 최종 후보로 유지
- 파일 처리 코드는 모두 `try/except`를 적용한다.
  - `password.txt` 읽기
  - `result.txt` 쓰기
  - 필요하면 사용자 입력값 처리도 숫자 검증 예외를 둔다.
- 스타일 제약을 반영한다.
  - 표준 라이브러리 외 사용 금지
  - 문자열은 기본적으로 작은따옴표 사용
  - 공백, 들여쓰기, 함수명, 상수명은 PEP 8 준수
  - 경고 없이 실행 가능한 단순한 콘솔 프로그램 구조 유지

## Public Interfaces
- `caesar_cipher_decode(target_text)`
  - 입력: 암호문 문자열 1개
  - 출력: 각 자리수별 해독 결과를 화면에 출력
  - 반환: 구현 선택은 가능하지만, 계획상 `list[tuple[int, str]]`에 해당하는 구조 또는 동일 의미의 리스트로 전체 결과를 돌려주면 재사용성이 높다
- `main()`
  - 파일 읽기, 해독 실행, 사용자 자리수 입력, 결과 저장까지 전체 흐름 담당
- 보너스용 보조 함수 1개 추가 권장
  - 예: `contains_dictionary_word(decoded_text, dictionary_words)`

## Test Plan
- `password.txt`가 정상 존재할 때 26개 자리수 결과가 모두 출력된다.
- 대문자, 소문자, 공백, 숫자, 기호가 섞여 있어도 알파벳만 회전한다.
- 사람이 올바른 자리수를 입력하면 해당 해독문이 `result.txt`에 저장된다.
- 자리수 입력이 숫자가 아니거나 범위를 벗어나면 오류 메시지를 출력하고 재입력 또는 종료 규칙을 따른다.
- `password.txt`가 없거나 읽기 권한이 없으면 예외 메시지만 출력하고 비정상 종료하지 않는다.
- `result.txt` 저장 실패 시 예외 메시지를 출력한다.
- 보너스 모드에서 사전 단어가 해독 결과에 포함되면 조기 종료 메시지와 후보 자리수를 출력한다.
- 사전 단어가 없으면 기존 26회 전체 출력 흐름이 그대로 유지된다.

## Assumptions
- `week09`는 현재 비어 있으므로 새 제출물 기준은 `week09/plan.md`, `week09/password.txt`, 구현 스크립트, 실행 결과 `week09/result.txt`로 잡는다.
- 자리수는 카이사르 복호화 관례에 맞춰 `0`부터 `25`까지 순회한다.
- 최종 정답 판정은 기본 과제 요구대로 사람이 출력 결과를 보고 선택하는 방식으로 유지한다.
- 보너스 과제의 사전은 외부 파일이 아니라 코드 내부의 간단한 단어 목록으로 구현한다.
- 구현 파일명은 아직 고정되지 않았으므로 `week09/caesar_decoder.py`를 기본안으로 사용한다.
