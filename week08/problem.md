# 단위문제 정의: 문제1 비밀번호 XXXXXX

## 1. 단위문제 개요
| 항목 | 내용 |
| :--- | :--- |
| **단위문제명** | 문제1 비밀번호 XXXXXX |
| **분야** | 컴퓨터공학 |
| **구분** | PYTHON |
| **학습시간** | 5시간 |

## 2. 스토리
좁은 화성 기지에 혼자 남게 된 지도 벌써 시간이 제법 지난 것 같다. 산소와 식량도 점점 떨어지고 있었다. 커피 한 잔이 간절히 생각나는 순간, 잔해 사이로 흐릿하게 'emergency storage'라고 적힌 문이 보였다. 하지만 문은 굳건히 잠겨 있었다.  
미션 컴퓨터 쿡북에 따르면 권한 있는 사용자는 컴퓨터에서 비밀번호를 확인할 수 있다고 한다. 찾아보니 `emergency_storage_key.zip` 파일이 발견되었지만, 이 파일조차 암호가 걸려 있었다. 이제 이 암호를 풀어 생존에 필요한 요소들을 찾아내야 한다.[cite: 1]

## 3. 수행과제
1.  **암호 해독 코드 작성**: `emergency_storage_key.zip`의 암호를 풀 수 있는 코드를 작성한다.[cite: 1]
    * 암호 조건: 특수 문자 없이 **숫자와 소문자 알파벳**으로 구성된 **6자리** 문자열이다.[cite: 1]
2.  **함수화**: 암호를 푸는 로직을 `unlock_zip()`이라는 이름의 함수로 정의한다.[cite: 1]
3.  **진행 상황 출력**: 암호를 푸는 과정에서 **시작 시간, 반복 횟수, 진행 시간** 등을 출력한다.[cite: 1]
4.  **결과 저장**: 암호 해독에 성공하면 해당 암호를 `password.txt` 파일로 저장한다.[cite: 1]
5.  **파일 저장**: 전체 코드는 `door_hacking.py`로 저장한다.[cite: 1]

## 4. 개발 환경 및 코딩 가이드
* **Python 버전**: 3.x 버전을 사용한다.[cite: 1]
* **라이브러리 제한**: Python 기본 명령어만 사용해야 하며 별도의 패키지 사용은 금지된다. 단, **zip 파일을 다루는 부분**은 외부 라이브러리(표준 라이브러리 `zipfile` 등) 사용이 가능하다.[cite: 1]
* **PEP 8 스타일 준수**:[cite: 1]
    * 문자열은 작은따옴표(`' '`) 사용을 기본으로 하되, 필요한 경우에만 큰따옴표(`" "`)를 사용한다.[cite: 1]
    * 대입문 `=` 앞뒤로 공백을 삽입한다.[cite: 1]
    * 들여쓰기는 공백(Space)을 기본으로 사용한다.[cite: 1]

## 5. 제약사항
* Python 기본 명령어 외 별도 라이브러리 사용 불가 (zip 관련 제외).[cite: 1]
* **예외 처리**: 파일을 다루는 부분에는 반드시 예외 처리가 포함되어야 한다.[cite: 1]
* 모든 코드는 경고 메시지 없이 정상적으로 실행되어야 한다.[cite: 1]

## 6. 보너스 과제
* 암호를 더 빠르게 풀 수 있는 효율적인 알고리즘을 제시하고 코드로 구현한다.[cite: 1]
